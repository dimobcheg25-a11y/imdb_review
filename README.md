# Мій IMDb-дашборд

Локальний дашборд з графіками й топами за вашими оцінками на IMDb. Дані про фільми (постери, жанри, країни, актори, режисери) підтягуються з TMDB українською.

- `index.html`: головний дашборд
- `year.html`: підсумки за рік

## Що потрібно

- Python 3.10 або новіший (сторонні пакети не потрібні)
- Безкоштовний акаунт на [TMDB](https://www.themoviedb.org/)
- Акаунт IMDb з вашими оцінками

## Налаштування

1. **Склонуйте репозиторій**
   ```bash
   git clone <url-репозиторію>
   cd imdb_review
   ```

2. **Отримайте токен TMDB**
   - Зареєструйтесь на themoviedb.org і відкрийте [Settings → API](https://www.themoviedb.org/settings/api).
   - Створіть API-ключ (тип Developer, мета: особисте некомерційне використання).
   - Скопіюйте **API Read Access Token**: довгий рядок, який починається з `eyJ...`.

3. **Створіть файл `.env`**
   ```bash
   cp .env.example .env
   ```
   Вставте токен після `TMDB_READ_TOKEN=`. Файл `.env` не потрапляє в git.

4. **Експортуйте свої оцінки з IMDb**
   - IMDb → ваш профіль → **Your Ratings** → меню `⋯` → **Export**.
   - Скачайте CSV і покладіть його в корінь проєкту під назвою `ratings.csv`.

5. **Зберіть дані**
   ```bash
   python fetch_tmdb.py   # качає дані з TMDB у cache/ (перший запуск триває кілька хвилин)
   python build.py        # збирає data.js
   ```
   На Windows можна просто запустити `update.cmd`: він виконає обидва кроки й відкриє дашборд.

6. **Відкрийте `index.html`** у браузері. Сервер не потрібен, сторінка працює просто з файлу.

## Оновлення

Експортуйте свіжий `ratings.csv`, покладіть його в папку й знову запустіть `update.cmd` (або обидва скрипти). `fetch_tmdb.py` докачує лише нові тайтли. Щоб перекачати все, запустіть `python fetch_tmdb.py --refresh`.

## Дані

Дані про фільми надає [TMDB](https://www.themoviedb.org/). Цей продукт використовує TMDB API, але не схвалений і не сертифікований TMDB.
